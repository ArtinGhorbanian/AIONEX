# AIONEX community conduct

AIONEX welcomes technically rigorous, good-faith participation. Repository discussions should remain safe, useful, and focused on the project.

## Expected behavior

- Be respectful across differences in experience, identity, language, and viewpoint.
- Critique code, evidence, and claims rather than people.
- Distinguish verified results from hypotheses, plans, and personal interpretations.
- Protect private information, credentials, unpublished research, and vulnerable-user data.
- Cite sources and disclose the provenance and license of contributed code, data, or media.
- Avoid medical advice, unsupported scientific certainty, endorsement claims, and promotional spam.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, deliberate credential exposure, deceptive scientific claims, plagiarism, and repeated disruption are not accepted.

## Reporting and enforcement

For ordinary conduct concerns, open a GitHub Issue with the minimum safe context or use the authenticated GitHub profile's available private contact channel. Security vulnerabilities follow [SECURITY.md](SECURITY.md). Do not post sensitive evidence publicly.

Maintainers may edit or remove content, close interactions, or restrict participation when necessary to protect people or the project. Decisions should be proportionate, documented when safe, and based on behavior rather than disagreement.
