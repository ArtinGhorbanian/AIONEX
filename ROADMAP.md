# Roadmap

This roadmap records plausible next work; it is not a promise, release date, or list of current features.

## Rights gate

- Recover the exact 2025 Participant Terms or obtain written organizer clarification.
- Confirm every contributor's authority to publish retained code under MIT.
- Reassess public visibility only after both items are documented.

## Near-term engineering

- Add a persistent, multi-process rate-limit/cache adapter for intentional shared deployments.
- Add provider contract tests against recorded, sanitized PubMed/OpenAlex fixtures.
- Add automated browser accessibility checks to the Linux CI workflow.
- Produce hash-locked dependency files when the update process can maintain them reliably.
- Add an operator-facing diagnostics page that exposes no secrets or article content.

## Research workflow exploration

- Export a saved reading list in a documented, portable format.
- Let users compare source abstracts side by side without generating scientific conclusions.
- Add opt-in citation export from canonical PubMed identifiers.
- Explore additional evidence-retrieval methods with an explicit evaluation set before changing the deterministic baseline.

## Explicitly out of scope

AIONEX will not present a discovery signal as scientific quality, truth, clinical advice, or a peer-review score. It will not silently send research text to an optional provider or bundle datasets whose redistribution rights are unclear.
