# Adaptation opportunities

These are credible extensions of the architecture, not features already implemented. No commercial offering is made while public-release rights remain unresolved.

## Domain-specific literature triage

Replace the initial query vocabulary and signal adapters for a defined public corpus while retaining source links, extractive evidence, transparent proxy semantics, and optional-service boundaries. A regulated domain would require specialist review, evaluation data, and deployment controls beyond this repository.

## Internal research reading hub

Add organization authentication and an approved persistent store for shared reading lists and annotations. The current local-only storage and loopback defaults are useful prototypes, but they are not multi-tenant controls.

## Curated evidence-monitoring workflow

Schedule saved searches through provider-compliant jobs and notify reviewers only about normalized metadata changes. This would require durable queues, deduplication, operator observability, and rate-limit coordination; none is present today.

## Transparent metadata dashboard

Adapt the five-signal contract to a customer-owned, documented set of discovery indicators. Every indicator should retain raw values, provenance, availability, scaling, and limitations. It must not be relabeled as truth, quality, or impact without a defensible validation study.

## Accessible public-data explorer

Reuse the same-origin API boundary and semantic UI for another openly licensed dataset. Before implementation, establish dataset redistribution rights, retention rules, expected user risk, and an accessibility test matrix.
