# Verified demo script

This five-minute script uses only implemented behavior. Run it on loopback with chat and translation disabled unless those providers are intentionally configured.

## 1. Frame the problem — 30 seconds

Explain that public space life-science literature is easy to search but slow to triage. AIONEX is a reading aid: it does not score truth, replace peer review, or give medical advice.

## 2. Search — 45 seconds

Enter `microgravity bone loss` and select **Search PubMed**. Point out that results come from live NCBI E-utilities and retain canonical PubMed links.

## 3. Investigate — 90 seconds

Open the article beginning “The Critical Role of the Piezo1/β-catenin/ATF4 Axis.” Show the source metadata, deterministic extractive brief, and expandable source abstract. Explain the method/source-sentence disclosure.

## 4. Inspect context — 60 seconds

Walk through citations, PMC availability, recency, source activity, and author activity. Show raw values and sources, then read the methodology and limitations. When OpenAlex is not configured, explain why optional activity signals remain unavailable rather than guessed.

## 5. Retrieve evidence — 45 seconds

Ask: `What happened to bone formation under simulated microgravity?` Show the selected source sentence and lexical **term match** label. Emphasize that it is not a model-confidence probability.

## 6. Demonstrate product care — 45 seconds

Save the article, open Library, close with Escape, switch to Arabic to show RTL, and demonstrate dark/system themes or the mobile screenshot. Mention that saves/history remain on the device.

## 7. Close — 25 seconds

Show the architecture and validation documents. State the optional-service privacy boundary and current private rights-review status. Do not claim NASA affiliation, an award, production deployment, customers, or public availability.

## Recording checklist

- Use a fresh browser profile with no personal bookmarks, notifications, or local records.
- Keep API keys, terminals containing environment values, and local paths off screen.
- Record the actual running application; do not composite unimplemented states.
- Add captions and a transcript.
- If the video is intended for a Space Apps submission page, re-check the exact applicable branding, AI-disclosure, and commercial-promotion rules first.
